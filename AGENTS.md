# Hokka — architecture

A single-user PWA that tracks paid invoices and business receipts for an Ontario sole proprietor, splits every entry into a pre-tax amount and an HST amount, and reports net HST owing plus an income-tax reserve.

House style is [REPO_GUIDELINES.md](../REPO_GUIDELINES.md). The product plan is [hst-expense-manager-project.md](../hst-expense-manager-project.md); where the two disagree about the product, the plan wins, and where they disagree about code shape, the guidelines win.

One deliberate deviation: the guidelines ban comments outright, this repo allows them where a rule is a tax rule or a browser quirk that no name can carry — why HST and the pre-tax amount are stored apart, why a date is read locally, why a `localStorage` read is wrapped. A comment that restates the code is still wrong.

## Stack

TypeScript, React 19, Next.js App Router, Emotion, Radix primitives, Phosphor icons. No Tailwind, no CSS modules, no second headless library, no state-management library.

## Invariants

| Rule                                                                    | Why                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                             |
| ----------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Every transaction stores `subtotal`, `hstAmount` and `total` separately | The pre-tax amount drives the income-tax deduction; the HST amount drives the Input Tax Credit. They are different numbers answering different questions.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       |
| `claimablePct` lives on the transaction, defaulted from the category    | Meals cap at 50%, personal items at 0%. Storing the percentage on the row keeps historical entries correct when a category default changes.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                     |
| No stored balances                                                      | Every dashboard figure is recalculated on read by [src/lib/tax.ts](src/lib/tax.ts). A cached "current owing" drifts; a derived one cannot.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      |
| The income-tax reserve rate is derived, not configured                  | [src/lib/incomeTax.ts](src/lib/incomeTax.ts) runs net income through the federal and Ontario brackets plus self-employed CPP in [src/data/incomeTaxRates.ts](src/data/incomeTaxRates.ts). `settings.incomeTaxReservePct` is `null` by default and only overrides that estimate when set.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                        |
| Filings are inserts, never edits                                        | Logging a remittance adds a `filings` row and the dashboard nets it out. The dashboard's obligation cards read that history and link into the filing form; they never write one themselves, so nothing is ever reopened. History stays intact for a CRA review.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 |
| Data access goes through the port                                       | Every read and write crosses [src/data/repository.types.ts](src/data/repository.types.ts), so the storage driver stays swappable. Nothing above it knows Supabase exists.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       |
| Writes land locally, then queue                                         | The repository writes the IndexedDB mirror and enqueues an outbox op; it never awaits the network. A form submitted on a subway platform is saved, not lost. See [docs/data-layer.md](docs/data-layer.md).                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      |
| Screens read the mirror, never the network                              | [src/context/Ledger](src/context/Ledger) subscribes to the local stores with `useSyncExternalStore`, so a write shows up before it syncs and a pull shows up without a refetch.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 |
| An attachment is compressed before it is stored                         | [src/lib/compress](src/lib/compress) re-encodes an image to WebP and rebuilds a scanned PDF before the blob reaches the mirror, so the offline copy, the upload and the bucket object are all the small one. Alpha is carried through and there is no JPEG fallback, so a transparent PNG never lands on a white square. Every failure path keeps the original file. See [docs/compression.md](docs/compression.md).                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                            |
| A receipt file leaves the device only once                              | The blob sits in IndexedDB until R2 confirms the upload, then it is deleted. The row stays in the mirror so the app still reads offline.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                        |
| No Supabase or R2 credential reaches the browser                        | Every call goes through a route handler in [src/app/api](src/app/api), which holds the service role key and signs R2 URLs. RLS is on with no policies, so the anon key opens nothing.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                           |
| The API is gated in one place                                           | [src/middleware.ts](src/middleware.ts) turns away every `/api/*` request without a session cookie signed by [/api/unlock](src/app/api/unlock/route.ts) from `PASSWORD`; only `/api/unlock` and `/api/health` are open. [src/components/LockGate](src/components/LockGate) is the screen in front of that gate, not the gate, and a 401 from any route clears its flag. `NEXT_PUBLIC_UNLOCKED_IN_DEV=true` waves both past for local work through [src/lib/devUnlock.ts](src/lib/devUnlock.ts); it is read beside `NODE_ENV === "development"`, so a production build drops it.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                  |
| The unlock is a session, never a stored flag                            | [src/lib/platform/unlocked.ts](src/lib/platform/unlocked.ts) keeps a stamp in `sessionStorage`, so closing the app or the tab locks the ledger with no timer involved. The stamp expires after five idle minutes and is cut to a minute the moment the tab is hidden, since a hidden tab may be a phone in someone else's hand. A flag that outlived the session left the ledger open on a borrowed device.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                     |
| Biometrics open the screen, never the gate                              | [src/lib/biometrics](src/lib/biometrics) enrols a platform WebAuthn credential and keeps its id on the device, never in settings and never synced, so the toggle means "this device". The prompt is raised on arrival and says nothing when it fails, since an error over an untouched screen reads as a refusal of a password nobody typed; the button raises the same prompt and does speak. Only one is ever in flight, because WebKit holds one WebAuthn request per page and ignores the abort signal meant to cancel it, so a second prompt raised over a live one never resolves and strands the screen. `allowCredentials` carries `transports: ["internal"]` for the same reason: without it WebKit weighs a security key and a phone over the air as well, and raises no prompt at all rather than refusing. A dismissed or failed prompt falls straight through to the password, and `GET /api/unlock` says whether the session cookie is still alive so a lapsed session asks for the password rather than a fingerprint that could never stick. Offline the assertion stands alone, because a local ledger should still open on a subway platform. |
| A date is a calendar date, never an instant                             | [src/lib/dates.ts](src/lib/dates.ts) is the only place that reads today, parses a stored `YYYY-MM-DD` or formats one for the screen, and [currentPeriod](src/lib/periods.ts) takes that string rather than a `Date`. `periods.ts` builds its own boundaries with a private `utcIsoDate`, because a period edge is a synthetic date with no local meaning. Reading either in UTC hands you tomorrow all evening in Ontario, which would file a transaction into the wrong period.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                |
| Ten colour tokens, and no eleventh                                      | Five `surface.*` roles and five `foreground.*` roles, declared in [src/app/globals.css](src/app/globals.css) and reached only through [src/lib/theme.ts](src/lib/theme.ts). A style that wants another colour is a design decision, not a code one.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                             |
| A category carries a hue, and the hue is a scale                        | The ten roles stay ten. The eight `--category-*` hues in [src/app/globals.css](src/app/globals.css) are a named scale like `fontSize` or `space`, reached through `theme.categoryColor` and tinted by `categoryTint`. A category names its hue in [src/data/categories.ts](src/data/categories.ts), so the colour follows the category everywhere rather than being picked per screen.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                          |
| Everything else is a named scale on the same object                     | `fontFamily`, `fontSize` (`xs`–`5xl`), `borderRadius` (`xs`–`xl`, `full`), `space`, `layout`, `motion`. No one-off tokens for a single component's height or inset — those are local values in that component's styles.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                         |
| Every page lays out on the same grid                                    | 12 columns, an 80px outer gutter (40px at `lgTablet` and below, 16px on mobile) and a 40px column gap, capped at 900px and 1440px above the `desktop` breakpoint. Declared in [src/app/globals.css](src/app/globals.css), consumed only through [src/components/Grid](src/components/Grid). A page that lays itself out by hand drifts from every other page.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                   |
| The rail is sticky, the content scrolls                                 | [src/components/AppShell](src/components/AppShell) holds the rail 80px to the left of the content at every width, centres the pair in the viewport so a capped page does not sit stuck to the left edge, and lets the right column run past the fold. Rail width, collapsed width and the gap are tokens, not literals.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                         |
| The summary deck is one DOM tree at every width                         | [src/app/_components/SummaryDeck](src/app/_components/SummaryDeck) is `display: contents` above `smTablet`, so its three panels are grid items of the page grid; below it, the same element becomes an edge-bleeding scroll-snap carousel. One tree means no layout hook, no hydration flash and no second copy to keep in step.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                |
| Every gesture has a button                                              | [src/components/SwipeRow](src/components/SwipeRow) commits its action on a horizontal drag, but the same action is always present as a real focusable control in the card it wraps. The revealed panel is `aria-hidden`. A swipe is an accelerator, never the only way to reach something.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      |
| Every hover fill is the same mix                                        | `hoverFill` in [src/lib/theme.ts](src/lib/theme.ts) returns `color-mix(in srgb, <the element's own background>, var(--foreground-primary) 5%)`. No `filter: brightness`, no opacity fade, no hand-picked second colour. A transparent element passes `"transparent"` and resolves to a 5% foreground wash, which composites to the same colour as mixing against the container behind it.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       |
| A receipt is read on the device or not at all                           | [src/lib/ocr](src/lib/ocr) runs Tesseract and pdf.js from `public/ocr/`, synced out of `node_modules` by [scripts/sync-ocr-assets.js](scripts/sync-ocr-assets.js). A PDF with a text layer is read without OCR at all; a scan is rendered and recognised. No receipt image and no parsed figure crosses the network to be read, and the reader works offline once the assets are cached. See [docs/ocr.md](docs/ocr.md).                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                        |
| A reading never invents tax                                             | The parser splits a receipt into subtotal, tax and tip from its own labels and derives only the missing one. A receipt with no tax line is read as untaxed rather than back-solved at the HST rate, so a zero-rated purchase never claims an Input Tax Credit it is not owed.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                   |
| The rail opens on hover intent only                                     | [src/components/NavBar/useNavCollapse.ts](src/components/NavBar/useNavCollapse.ts) rests the rail collapsed and expands it after a 2s hover, closing again on mouse-out, outside click or Escape. There is no pin and no chevron, so nothing about the open state survives a navigation.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                        |

## Tooling

`scripts/` is plain Node, ESLint-ignored, never imported by app code. The codemods share [scripts/lib/module-paths.js](scripts/lib/module-paths.js), which is the one place that knows this repo resolves `@/` to the repo root — change an alias in `tsconfig.json` and change it there too. Commands are listed in [.claude/CLAUDE.md](.claude/CLAUDE.md).
